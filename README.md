# Högoms skola – dagens skolmat (RSS)

RSS-flöde för dagens skolmat från Mateo Meny, Högoms skola.

Källa: https://meny.mateo.se/sundsvall/673

När GitHub Pages har aktiverats är adressen:
https://e88lindstrom.github.io/hogom-skolmat/skolmat.xml

## Aktivera
1. Gå till Settings → Pages i repositoryt.
2. Välj Deploy from a branch, main och /docs. Klicka Save.
3. Gå till Actions → Uppdatera skolmat RSS → Run workflow.
4. Kontrollera att körningen lyckas och att RSS-adressen öppnas.
5. Klistra in adressen i WebPanels RSS-widget.

Schemalagda Actions körs flera gånger på vardagar. GitHub kan fördröja schemat. Mateo-API:et är inte officiellt dokumenterat och kan ändras. Om hämtningen misslyckas publiceras ingen ny fil.
